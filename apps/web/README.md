# @mxpro/web

Front-end Angular da plataforma MXPro: painel do organizador, cronometragem (PWA) e resultados ao vivo.
Veja o [README principal](../../README.md) para visão geral, rotas e como rodar.

```bash
pnpm exec ng serve                 # http://localhost:4200
pnpm exec ng build                 # build de produção em dist/web
pnpm exec ng test --watch=false    # testes unitários (Vitest)
pnpm typecheck                     # checagem de tipos
pnpm exec ng generate component features/<area>/<nome>
```
